BOSH SAHIFA

Bu saytda siz veb-sayt yaratishning 3 asosiy tilini o'rganasiz:

HTML -- sahifaning skeletini (matn, rasm, tugma) yaratadi.

CSS -- sahifaga go'zal ko'rinish (rang, shrift, joylashuv) beradi.

JavaScript -- sahifaga harakat va mantiq qo'shadi (masalan, tugma bosilganda nima bo'lishi).

Yuqoridagi menyudan kerakli bo'limni tanlang.

HTML DARSI

HTML (HyperText Markup Language) -- sahifaning asosiy qurilishi. Har bir element "teg" (tag) yordamida yoziladi.

<h1>Bu sarlavha</h1>
<p>Bu oddiy matn</p>
<button>Bosing</button>

h1 -- katta sarlavha, p -- paragraf (matn), button -- tugma.

Har bir HTML teg ochiladi <teg> va yopiladi </teg>.

CSS DARSI

CSS (Cascading Style Sheets) -- HTML elementlariga rang, o'lcham va joylashuv beradi.

h1 {
  color: blue;
  font-size: 40px;
}

Bu kodda h1 elementining rangini ko'k va shrift o'lchamini 40px qilamiz.

CSS odatda <style> tegi ichida yoki alohida faylda yoziladi.

JAVASCRIPT DARSI

JavaScript -- sahifaga "jonlanish" beradi: tugma bosilganda, forma yuborilganda nima bo'lishini belgilaydi.

document.getElementById("tugma").onclick = function() {
  alert("Siz tugmani bosdingiz!");
};

Bu kod "tugma" nomli elementga bosilganda ogohlantirish oynasini chiqaradi.

Ushbu sayt ham JavaScript yordamida Supabase bazasiga ma'lumot yozadi va o'qiydi!

RO'YXATDAN O'TGAN O'QUVCHILAR

    YO'RIQNOMA: SUPABASE'NI SOZLASH

    1. supabase.com saytiga kiring va bepul hisob oching, so'ng "New Project" tugmasi orqali yangi loyiha yarating.
    2. Loyiha ochilgach, chap menyudan "SQL Editor" bo'limini oching, shu fayl boshidagi SQL kodni to'liq nusxalab, "RUN" tugmasini bosing.
    3. Chap menyudan "Project Settings" -> "API" bo'limiga o'ting. U yerda "Project URL" va "anon public" kalitini topasiz.
    4. Shu ikki qiymatni ushbu faylning pastidagi <script> qismida SUPABASE_URL va SUPABASE_ANON_KEY o'zgaruvchilariga joylashtiring.
    5. Faylni saqlab, brauzerda ochib sinab ko'ring: ro'yxatdan o'ting, keyin kiring.
    6. Agar "row-level security policy" haqida xatolik chiqsa -- bu SQL'dagi policy (siyosat) to'g'ri yaratilmagan degani. SQL Editor'ga qaytib, 3- va 4-qadamdagi "create policy" buyruqlarini qayta ishlatib ko'ring. Jadval nomi "foydalanuvchilar" ekanini tekshiring.
